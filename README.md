# Python Journey · 学习成长花园

纯前端的 Python 学习成长管理应用：学习路线 + 动态每日计划 + 学习记录 + 植物领养与成长。
没有后端、没有账号、没有 AI 接口，所有数据保存在浏览器 `localStorage`。

## 启动

```bash
npm install
npm run dev        # http://localhost:5188
```

其他命令：

```bash
npm run build      # tsc -b + vite build
npm run preview    # 预览构建产物 http://localhost:4188
npm test           # 48 个单元测试（vitest）
npm run test:e2e   # 18 个端到端测试（Playwright，使用本机 Chrome）
node scripts/gen-assets.mjs   # 重新生成 57 张植物阶段图 + 背景图
node scripts/shots.mjs        # 截取各页面截图到 shots/
```

## 学习计划规则

- 每天的计划由 `services/taskGenerator.ts` 生成：时长 → 各板块分钟数（回顾/新知识/练习/独立实践/总结）；精力疲惫、意愿低、难度偏好共同决定任务数量。
- **知识点按顺序推进**：每个主题记录已学到第几个知识点（`progress.pointsDone`），每天学的是「接下来的 N 个」，不会每天从第一个重新学。一个主题的知识点全部学完才进入下一个主题。
- 只有记录「完全掌握 / 基本掌握」才会推进游标；「还需要复习 / 今天没有完成」保留同一切片并计入 `reviewCount`，连续三次没掌握后任务自动拆小。
- 回顾任务引用**昨天实际学过的点**（「回顾昨天：A、B」）；没有前序记录时回顾上一节的那一个点，避免凭空回顾。
- 阶段 2–6 拆成单知识点主题（一天一个清晰线索），阶段 1 仍按每周一个主题、多个知识点。
- 已存在的计划不会被重新生成覆盖；手动改过的计划（`edited`）和已有完成任务的计划一律拒绝重新生成。
- 休息日只给两件轻松的任务，不推进知识点。

## 植物成长规则

- 经验来源：完成任务（每项 3，单日上限 21）、记录学习（+8）、写总结（+12）、推进知识模块（+25）、完成实践项目（+80）、完成阶段（+120）。
- 经验累计跨过阶段阈值即切换形态并写入成长时间线；记录学习时浇一次水，同一天不会重复浇水。
- 植物不会因为断开学习而枯萎，也不按日期自动成长。

## 每日节奏（怎么算出来的）

| 机制 | 规则 | 为什么 |
| --- | --- | --- |
| 名额（认知负荷） | 15/30/45/60/90 分钟 → 1/2/3/4/5 个名额；疲惫或不想学各减 1（至少 1） | 一次只处理少量新信息，避免"塞满但没消化" |
| 难度成本 | 概念密集/要动手的点占 2 个名额（`Topic.difficulty` = 3） | 难点给足时间，宁可一天只攻一个 |
| 间隔复习 | 学过的点在第 1、3、7、21 天自动回到「知识回顾」，每天最多 2 个（60 分钟以上可 2 个，短会话 1 个） | 间隔重复比"只回顾昨天"记得更久；复习过的点推进到下一间隔，四轮后退出队列 |
| 周节奏 | 每周六为综合练习日（不学新点，只做到期复习 + 一个综合练习 + 周总结），周日休息 | 交错练习与巩固，避免连续堆新内容 |
| 掌握推进 | 完全/基本掌握才移动知识点游标；复习/未完成保留同一切片 | 进度跟着理解走，不跟日历走 |

计划页会显示当天名额、新知识点数、到期复习数、本主题还需几天；首页显示按当前节奏本阶段还需要多少个学习日。

## 学习笔记与错题本

- 笔记按日期存 `notes[date]`，一天一条，切换日期不会互相覆盖；打开即自动关联当天的阶段、周次、知识模块和任务，并自动打上当天知识点标签（可按 `self` 这类知识点检索）。
- 笔记页右侧编辑器会在停止输入 0.7 秒后自动保存，`更新于` 显示保存时间；删除只影响当天。
- 错题包含题目、我的答案、正确答案、错因、知识点、来源任务与掌握状态（未掌握 / 复习中 / 已掌握）。状态只能手动修改，程序永远不会自动标记为已掌握。
- 计划生成时会挑最多 2 道同主题的未掌握错题作为「错题复习」任务；同一知识点错两次以上会额外安排一次针对性练习。已掌握的错题不再出现在计划里。
- 从学习计划的练习任务可以直接点错题图标，题目内容、知识点、日期、来源任务自动带入。

## 数据结构与存储

- 类型定义集中在 `src/types/index.ts`（Roadmap、LearningStage、WeeklyPlan、DailyTask、StudyRecord、UserSettings、Plant、PlantStage、PlantAdoption、GrowthJournal、Achievement…）。
- 存储键：`python-journey.data`，`schemaVersion = 4`（v1/v2 数据自动补齐：`notes` / `wrongQuestions` 为空，已完成主题视为知识点全部学完）。读取时校验，首次运行才写入默认值；导入先 `validateAppData` 校验，失败时原数据不动。
- 植物图片通过 `data/plants.ts` 的配置映射解析（`import.meta.glob`），组件里没有硬编码路径；缺图时渲染统一占位。

## 已知限制

- 单一浏览器本地数据，不跨设备同步。
- 植物阶段图是按统一规范程序化生成的矢量插画（每种植物 7–8 个阶段各不相同），不是照片级写实素材。
- 图鉴第一版全部植物可自由领养，解锁门槛只做展示。
- 移动端底部导航可横向滚动（8 个入口），窄屏下不是全部同时可见。

## 本地启动（桌面快捷方式）

桌面上的 `Python Journey.lnk` 指向 `start-python-journey.bat`：

- 服务已在跑 → 直接打开 http://localhost:5188/
- 没在跑 → 先启动 `vite`（固定 5188 端口、端口占用就报错而不是偷偷换端口），轮询到 200 再打开浏览器
- 没装 Node 或启动超时 → 窗口保留并给出中文提示，不会一闪而过

如果浏览器没自动打开，窗口里会打印地址，手动复制到地址栏即可。重新生成快捷方式：`powershell -ExecutionPolicy Bypass -File scripts/make-shortcut.ps1`
